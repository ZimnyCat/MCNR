API

mcnr.xyz/api/stats — статистика

online — количество игроков на сервере сейчас

onlinePlayers — список имён игроков на сервере сейчас

restart — время до рестарта в минутах

size — размер карты сервера в гигабайтах

total — количество игроков на сервере за всё время

uptime — время работы сервера с последнего запуска в минутах


mcnr.xyz/api/joindate?player=игрок — данные об игроке

first — время первого захода (unix-время, миллисекунды)

last — время последнего захода (unix-время, миллисекунды) или "Online"

name — имя игрока

playtime — суммарное время игры в часах
